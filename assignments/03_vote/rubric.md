# Rubric — Assignment 3 (total: 10)

- Program runs without errors ......................... 2
- Correct use of input() into a variable .............. 1
- Correct use of the two print() calls ................ 1
- Correct use of if ................................... 2
- Correct use of else ................................. 2

    points.                                   

The concept rows — input, print, if, and else — are judged
from the source code: award them even if a typo (missing
quotes, a misspelled name) breaks the run. The typo's cost
is losing the run and output rows, not the concept rows.
The prompt wording is not graded — any reasonable question
asking for the age is fine. Only the two messages
(`You can vote!` / `Too young, sorry!`) must match exactly.
